\chapter{Instruções de execução}\label{apendice:execucao}

O código está no repositório do grupo (\url{https://github.com/vinicius-10/FakeNews-Distribuidos}) e foi executado no Windows~11 e no Linux, com o mesmo comando nos dois sistemas. O único requisito é o Python~3.12 (CPython): a simulação usa apenas a biblioteca padrão. Duas bibliotecas são opcionais e usadas só nos experimentos, fora do cálculo das gerações: o \texttt{matplotlib}~\cite{Hunter2007}, que desenha os gráficos, e o \texttt{psutil}, que informa o número de núcleos físicos. Todos os comandos são executados na pasta raiz do repositório.

\section{Execução das versões}

As três versões aceitam os mesmos parâmetros da simulação: \texttt{-{}-linhas}, \texttt{-{}-colunas}, \texttt{-{}-geracoes}, \texttt{-{}-percentual} (fração inicial de espalhadores), \texttt{-{}-limiar} e \texttt{-{}-semente}, com os mesmos valores padrão do código original ($100 \times 100$, 50~gerações, 5\%, limiar~3 e semente~42). As melhorias são ligadas pelas opções \texttt{-{}-resistencia MIN MAX}, \texttt{-{}-bots FRACAO}, \texttt{-{}-estatisticas PASTA}, \texttt{-{}-animacao arquivo.html} e, na distribuída, \texttt{-{}-bits}.

{\small
\begin{verbatim}
# sequencial refatorada
python -m sequencial.fakenews_sequencial \
    --linhas 500 --colunas 500 --limiar 2

# paralela com 8 processos (ou --modo threads)
python -m paralelo.fakenews_paralelo \
    --linhas 1000 --colunas 1000 --limiar 2 --trabalhadores 8

# distribuida numa maquina so (4 workers em localhost)
python -m distribuido.executar_local --workers 4 \
    --linhas 1000 --colunas 1000 --limiar 2

# distribuida entre maquinas: o coordenador numa delas...
python -m distribuido.coordenador --host 0.0.0.0 \
    --porta 5000 --workers 3 --linhas 2000 --colunas 2000 --limiar 2
# ... e um worker em cada maquina, com o IP do coordenador
python -m distribuido.worker \
    --coordenador 192.168.0.10:5000 --escutar 0.0.0.0
\end{verbatim}
}
